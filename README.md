# sign-language-recognition
A deep learning-based project that recognizes sign language gestures using Convolutional Neural Networks (CNN) and attention mechanisms on image data (Sign Language MNIST dataset), aimed at improving accessibility and communication.

#Technologies Used
- Python
- TensorFlow / Keras
- CNN
- Attention Mechanism
  
# Dataset
- Sign Language MNIST
- ## 🔗 Dataset Link
https://www.kaggle.com/datasets/datamunge/sign-language-mnist

#Results
- CNN Accuracy: ~93%
- CNN + Attention Accuracy: ~87%
